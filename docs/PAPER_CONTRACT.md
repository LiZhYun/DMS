# DMS paper contract

Source: the supplied `paper/source/Coordination as Inference in MARL.tex` and its referenced figure assets. This file distinguishes manuscript facts, corrected mathematics, and declared implementation choices. It establishes acceptance criteria; it does not establish reproduced performance.

## Core idea that must survive redesign

Every agent infers the intentions of other agents from locally observed behavior, predicts their later behavior with a conditional generative model, and conditions its own policy and local value function on selected inferred intentions. Selection measures how removing one inferred intention changes its own action distribution, or uses the paper's alternative soft attention. No explicit communication, intrinsic reward, or centralized critic is needed for this core method. Intention modeling and coordination must each have an ablation.

The paper's optimizer is HAPPO style, using random agent order and sequential policy-ratio correction with local critics. A cleaner independent PPO implementation can retain the core idea under the user's authorized redesign, but must identify itself as `DMS + independent PPO`, not an exact restoration of every original update. Comparisons must use the same optimizer for the no-intention baseline. Parameter sharing across agents is also a declared design choice: the algorithm initializes separate networks for every agent.

## Information and timing contract

Use explicit observer and peer axes: `observed_action[environment, observer_i, peer_j, action_feature]`, with `visible[environment, observer_i, peer_j]`, recurrent history, and episode reset masks. Agent identity is public metadata. An implementation may flatten axes internally only if their ordering is reversible and tested.

At decision time t, agent i receives its local observation o_i(t), its own previous actions, and behavior of peer j that i could observe by t. An action-history implementation uses peer actions through t-1, never peers' concurrently selected actions a_j(t). Each observer maintains its own history and inferred latent for each peer. No agent may read another agent's private observation, recurrent state, encoder output, or inferred intention. An unavailable peer is represented by the stated missing-action token, not its true command from the rollout runner.

| Component | Permitted input | Forbidden input |
| --- | --- | --- |
| Execution prior | Observer-local recorded actions through t-1, visibility, public IDs | Future actions, hidden peers' commands, global state |
| Training posterior | Past and later suffix from the same observer's already collected trajectory | Data that the observer never observed |
| Decoder | Inferred latent and observed past; observed future suffix is a loss target | Feeding the future suffix to the acting policy |
| Actor and local critic | Local observation/history and intentions generated by that observer's prior | Joint observations or state; posterior future-informed latent |
| Optional privileged reconstruction | State only in the separately labeled training target branch | Claiming this variant uses exclusively local training information |

The paper assumes observable peer actions but does not specify the sensor API. Exact control commands are not automatically locally observable. In SMAC, audit the configured native ally-last-action features and visibility semantics; if an extra sensor is added, record that augmentation and compare every method under the same information. In MuJoCo, observing a joint's position/velocity does not mean observing its actuator torque command. Either document a local action sensor with explicit visibility or use a behavior proxy derived from local observations and label this adaptation. Broadcasting the runner's complete joint torque vector violates the strict default.

Store visibility when each action is observed. Do not reveal earlier hidden commands when a peer later becomes visible. Reset histories on episode boundaries, distinguish termination from time-limit truncation for bootstrapping, and exclude padded or missing targets from auxiliary loss. The manuscript does not decide whether an old inferred intention persists while a peer is out of view; specify the choice and test that no new hidden information enters it.

## Intention model and corrected loss

The method section (source lines 380-411) splits an observed trajectory into A_P = A[1:T_sep] and A_F = A[T_sep+1:T]. The posterior and prior share weights; their inputs differ:

```
h_p = LayerNorm(GRU(A_P))
h_q = LayerNorm(GRU(concat_time(A_P, A_F)))
p(I | A_P)       = DiagonalNormal(mu(h_p), sigma(h_p))
q(I | A_P, A_F)  = DiagonalNormal(mu(h_q), sigma(h_q))
I_q = mu_q + sigma_q * epsilon, epsilon ~ Normal(0, 1)
loss_intention = mean_valid(negative_log_likelihood(A_F | I_q, A_P))
                 + KL(q || p)
```

The Gaussian parameters must have a consistent variance convention and positive bounded standard deviation. The analytically correct diagonal KL is:

```
sum_d [ log(sigma_p[d] / sigma_q[d])
        + (sigma_q[d]^2 + (mu_q[d] - mu_p[d])^2) / (2 * sigma_p[d]^2)
        - 1/2 ]
```

The manuscript prints the logarithm in the opposite direction at lines 479-484. Its Gaussian expression at lines 460-465 is a negative log likelihood although labeled as log likelihood. Use the corrected likelihood and KL terms; identical distributions must have zero KL, and arbitrary valid distributions must have nonnegative KL within numerical precision.

The normalization of these terms must also be explicit. A canonical sequence ELBO sums valid future likelihood terms and charges one KL per sequence. The current implementation averages likelihood over valid time/peer targets and KL over eligible peer sequences, with configurable `kl_beta`. Its effective sequence KL weight is `kl_beta × valid_targets / eligible_sequences`; it equals `kl_beta × H` for fully observed H-step futures. This time-normalized beta objective preserves the variational inference mechanism but must not be described as the canonical sequence ELBO at beta=1. [The intention diagnosis](INTENTION_DIAGNOSIS.md) records this distinction and the development experiments.

The continuous decoder predicts delta_a(t+1) = a(t+1) - a(t), then reconstructs a(t+1) = a(t) + predicted_delta. A valid delta target needs both endpoint actions to have been observed. The DMS_train figure depicts a recurrent autoregressive decoder; teacher forcing is a declared training choice. For discrete actions, use categorical likelihood of the next action. Integer action IDs have no meaningful Euclidean difference; residual categorical logits or next-action classification is the explicit resolution of the paper's general delta wording. Do not multiply cross entropy by the integer label as a literal reading of its categorical equation might suggest.

Only the prior supplies acting-policy latents. Stochastic prior samples used during rollout must be reproducible when recomputing PPO likelihoods, or use a declared deterministic prior summary. Auxiliary updates must not silently invalidate the collected old log probabilities, recurrent states, or behavior distribution. Record whether actor/value gradients update the intention model: the manuscript permits these gradients, whereas a frozen auxiliary representation is a redesign that needs disclosure.

## Coordination variants

For every available peer j, compute the paper's intervention score (lines 418-427):

```
p_full = policy_i(local_observation, all_inferred_peer_intentions)
p_without_j = policy_i(local_observation, same_intentions_with_j_removed)
C_ij = KL(p_full || p_without_j)
keep_ij = (C_ij > delta), default delta = 0.6
```

Use the same sampled intentions, local observation, recurrent state, and legal-action mask in both evaluations. Removing j must change only j's contribution. Sum KL across action coordinates for a factorized continuous distribution; do not compare sampled actions or value predictions. Exclude self edges. For no selected peers, the context is a well-defined zero vector. Thresholding is a hard selection and is not learned by ordinary backpropagation. Compute all scores from the unfiltered context, then select once; recursively filtering while scoring changes the definition.

The attention variant uses `e_ij = softmax_j(dot(I_i, I_j))` and a weighted sum of peer intentions. I_i must be inferred from i's own observed action history, not copied from another agent. Mask invalid/self entries before normalization and handle an entirely masked row without NaNs. Scaled dot products or learned projections are declared improvements. The ablation section explicitly presents CI and Attention as two alternative variants; combining hard CI and attention is a third, newly declared variant.

Long/short intention filtering (lines 432-440) compares the full-history prior with the same network applied to the last l=4 observed actions. If its KL exceeds K=1e4, those l actions are masked. KL direction, when the comparison happens, and how recurrent state is recomputed after rejecting a segment are unspecified; choose and log them. Rejecting a segment without repairing already accumulated recurrent state does not actually remove its influence. Missing observations use a zero action vector plus the peer's ID; add an explicit visibility bit to distinguish missing data from a real zero action, and document that small clarification.

## Optimization and strict-local default

The actor and critic both condition on enhanced local observations. The critic uses local value targets and the shared environment reward; GAE is specified but its lambda is missing. Actor improvement uses a clipped HAPPO/PPO ratio. The first 100 episodes act without intention. The pseudocode begins DMS training after warmup; training the CVAE during warmup is a permissible, declared redesign. Define whether an 'episode' means a completed environment episode or vectorized rollout update; they are not interchangeable.

The paper alternates d=2 DMS updates with one actor/value update, and applies soft updates `theta_effective = rho * theta_updated + (1-rho) * theta_old` to stabilize DMS. It provides no numeric rho. The prose defines update delay more clearly than the pseudocode's incomplete `if k mod d`; implement a documented schedule. A maintained target encoder is a declared implementation of stabilization, not proof that the paper used one.

The optional state-feature reconstruction loss at lines 494-498 requires global state during training. Default it OFF for the strict-local method. If provided as a separate privileged-training variant, correct the missing square/parentheses and use a fixed or otherwise noncollapsing target representation. An unconstrained trainable encoder on both sides can minimize the loss by returning a constant; a low reconstruction loss alone is not evidence that intentions recover global information.

## Benchmark and hyperparameter ledger

Exact SMAC targets are in `configs/paper_targets.json`, source table `eval-smac` (lines 903-915): 3s5z 97.5% (SD 2.2 percentage points), 8m_vs_9m 82.6% (6.1), and MMM2 62.1% (8.8), each at 10 million environment steps. The paper states six training seeds and ten test games after each training phase, with a 'median winning rate'; the aggregation yielding its nonmultiples of 10% is not specified. Preserve the table's reported numbers without pretending that protocol is fully reconstructable.

MuJoCo main figures contain Ant 2x4/4x2/8x1, HalfCheetah 2x3/3x2/6x1, and Walker 2x3/3x2/6x1. All x axes span 1e7 environment steps. The configuration table also lists ManyAgentSwimmer 10x2; its cited results are parameter studies. The bundled `10x2_Agent_Swimmer.pdf` is not included in the main-results TeX. MuJoCo final returns and standard deviations are not tabulated; the JSON labels approximate plot readings and conservative engineering targets separately. Shaded bands have unspecified semantics and must not be treated as recoverable seed-level data.

There is a material MuJoCo conflict: environment prose (line 594) says observation distance k=1, while every row of `config-mujoco` (lines 963-983) says Agent Obsk=0. Support and report both sensitivity settings, use table value 0 for a declared table-faithful track, and do not claim either is definitively the historical experiment setting. Pin environment package versions, MuJoCo engine/version, reward defaults, episode limits, SMAC map checksums, StarCraft version, difficulty, and observation flags. Gymnasium/PettingZoo modern environments are adaptations until their comparability to the original benchmark has been audited.

## Reviewable reproduction acceptance

Use separate development and final seeds, predeclare the final checkpoint rule and step budget, save raw per-episode evaluations and per-seed summaries, and report mean, median, standard deviation, and seed-level uncertainty. The JSON's stronger evaluation episode counts are an engineering protocol, not a manuscript fact. Report both the paper-comparable statistic and the new protocol's statistic. Match environment settings and count environment transitions, not transitions multiplied by number of agents.

Required comparisons are no intention (same PPO/HAPPO base), intention without coordination filtering, causal hard selection, attention alternative, and missing-action handling; include long/short filtering sensitivity. Baselines and variants must have matched information access and comparable tuning/compute budgets. Show latent variance, held-out behavior prediction quality versus a persistence predictor, KL, selected-peer rate, and missing-input frequency so policy gains cannot conceal an inactive intention module or data leakage.

Readiness requires runnable pinned environments, meaningful invariance/sequence/loss tests, all registered seed runs at matched budgets, archived final evaluations exceeding every primary target, ablations supporting the intended mechanism, and a fresh-reader walkthrough. A single lucky seed, a short smoke run, higher scores in a different benchmark version, or an aggregate obtained by choosing each seed's best test checkpoint does not satisfy the user's request. No performance above the paper is established until those artifacts exist.
