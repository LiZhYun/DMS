# Paper illustrations

`dms-overview.png` reproduces the architecture illustration supplied with
**Coordination as Inference in Multi-Agent Reinforcement Learning**, Li et al.,
*Neural Networks* 172 (2024), 106101.
[Published article](https://doi.org/10.1016/j.neunet.2024.106101).

The image was recovered from the original manuscript’s `DMS.eps` raster stream
at its native 4,800 × 1,644 resolution. The EPS ASCII85/RunLength encoding was
decoded and its RGB pixels saved losslessly as PNG, without altering the labels,
layout or scientific content. The figure represents the published architecture;
implementation differences are described in
[the implementation decisions](../IMPLEMENTATION_DECISIONS.md).

This paper illustration is attributed to the paper’s authors and is not
relicensed by the software’s MIT license. Manuscript sources and the full
publisher PDF are not bundled in this repository.
